Heat diffusion on a grid

A metal plate is cut into an N × N grid. The edges are held at fixed temperatures. Every other cell repeatedly takes the average of its four neighbours until nothing changes any more.

Why it stops

Two grids

Each sweep reads the old grid and writes a new one, then the two swap. Reading from the old grid only is what makes this Jacobi iteration. Updating in place would be Gauss–Seidel.

Max change

While computing each cell, keep the largest |new − old| seen across the grid. That single number measures how far the plate is from rest.

Fixed edges

Boundary cells are never updated. They act as permanent heat sources and sinks, so the interior settles on a smooth blend between them.

read N, grid T, boundary values, epsilon
copy T into T_new
iter = 0
repeat
    max_diff = 0
    for i in 1 .. N-2:
        for j in 1 .. N-2:
            T_new[i][j] = (T[i-1][j] + T[i+1][j] + T[i][j-1] + T[i][j+1]) / 4
            max_diff    = max(max_diff, |T_new[i][j] - T[i][j]|)
    swap(T, T_new)
    iter = iter + 1
until max_diff < epsilon
print T, iter, elapsed time

The three stat tiles above match the three outputs the program must report: the final grid, the iteration count and the execution time. Larger N and smaller ε both raise the iteration count.
